# Public beta release notes

The public-beta release line introduces macOS installers, application updates chosen by the user, version-pinned Codex activation, and public bug reporting. Read the distribution notice attached to each release: a community beta is ad-hoc signed and not notarized by Apple. Its independent update signature is not Apple approval.

Updates appear in the account menu. Downloads are manual; installation and restart are a separate action and cannot interrupt active work.

Existing 0.1.0 users need to install the first updater-enabled beta manually. Chats, account profiles, preferences, generated previews and worktree bindings are retained. Back up important data before using beta software.

The bundled engine includes the matching Code Mode host, so tool execution does not depend on a missing development runtime component. Installation and startup validate both components before activation.

Browser, Computer Use and Plugins remain experimental. Some capabilities require separately installed upstream components; they are not all included in the standalone app. See the integration guide.

Initial supported systems: Apple Silicon and Intel Macs running macOS 15 or newer. Windows, Linux and Mac App Store distribution are not included.
